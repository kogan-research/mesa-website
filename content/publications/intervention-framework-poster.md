## Overview

This project aims to develop a comprehensive intervention framework for major types of misleading visualizations and a proof-of-concept automated intervention generation system. We have compiled a corpus of misleading or recontextualized chart and caption pairs. We are doing a design exercise, where researchers create the best-case intervention for each misleading post. We will code and analyze the resulting interventions to derive an intervention framework or design space.
